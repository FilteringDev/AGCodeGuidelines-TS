# @agcodeguidelines/rule-catalog

Pinned source hashes, effective inherited sample settings, rule mappings, and dispositions for all 134 numbered AdGuard JavaScript guideline clauses.

Import `catalog` and `severity` from the package. The catalog distinguishes native, JavaScript, custom, compiler, manual, overridden, and disabled behavior. Sample settings take precedence over conflicting prose. Compiler and manual dispositions are part of the policy's documented contract.
